# Orbital Aerospace UI Designs

Design screens for "ORBITAL AEROSPACE", a website concept for an aerospace and orbital launch company. Each screen is exported as a standalone HTML page with a matching screenshot.

## Screens

| Folder | Contents |
|---|---|
| `homepage_orbital_aerospace_updated` | Home page ("Beyond The Horizon") |
| `orbital_aerospace_platform` | Platform page ("Beyond The Horizon"), HTML only |
| `mission_control_dashboard_updated` | Mission Control dashboard |
| `missions_orbital_aerospace_updated` | Missions |
| `launch_centers_global_network` | Global network of launch centers |
| `fleet_catalog_updated` | Fleet catalog |
| `technology_orbital_aerospace_updated` | Technology |
| `news_media_hub` | News & Media hub |

Every folder has `code.html` (the page) and, except `orbital_aerospace_platform`, a `screen.png` preview.

## Design system

`astra_nova/DESIGN.md` documents the design system behind the screens, called "The Celestial Navigator":

- **Colours**: Photon Blue `#98cbff` (primary), Deep Space `#121318` (background surface), Emergency Orange `#ffb59a` (critical actions) and Metallic Silver `#c6c6c6` (secondary).
- **Layering**: surfaces are separated by tonal shifts instead of 1px borders, with glassmorphism (blurred, semi-transparent) for floating panels.
- **Typography**: Space Grotesk for display text and labels, Manrope for body text and technical specs.
